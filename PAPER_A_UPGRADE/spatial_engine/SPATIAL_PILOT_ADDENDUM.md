# Spatial pilot implementation choices, 24 October 2026

Written before executing this new pilot, after exposure to the study results. This is not external preregistration. The pilot checks code and runtime only; no procedure will be selected from pilot rejection rates.

Geometry: the 63-province snapshot already in portable_checks/inputs/provinces.geojson. Its 63 polygon geometries were checked exactly equal to GIS_DERIVED/CANONICAL_ADM1_63.geojson. Sort by shapeISO. Use polygon intersections for adjacency; any isolated province is connected symmetrically to its nearest centroid. Compare a symmetrized five-nearest-neighbour graph. Record edges, isolated-province repairs, connected components and hashes. Polygon centroids are computed in source longitude/latitude, as in the earlier check. Distances for the new kernel are chord distances on a sphere of radius 6371.0088 km, embedding these centroids in three-dimensional Euclidean space; not degrees treated as kilometres. Retain the earlier equirectangular coordinates for its k-means groups.

DGP: row-standardized W, L=(I-rho W)^(-1), normalize each row of L to Euclidean length one. The Gaussian covariance L L' is positive definite with unit diagonal. rho values 0, .3, .6, .85 are parameter levels, not claims that observed Moran's I has these values. Cross-channel covariance C=[[1,.45,.25],[.45,1,.25],[.25,.25,1]]. Time covariance is AR(1), coefficient .7, across 16 quarters. Generate the joint spatial/time/channel Gaussian array, not independent windows. Use first and fourth years' quarters for endpoint contrasts. The third channel is X for Delta in the first quarter; optional rounding of X is recorded with its actual tie fraction.

Targets: Delta=rho(V,X)-rho(O,X)=0 by exchangeability of the entire V and O fields (also after rounding X). Q2 rho(first year)-rho(fourth year)=0; mean-quarterly rho(fourth year)-rho(first year)=0 by stationary joint marginal law. Spearman correlation of Q2 Gaussian log-speed changes has population target 6/pi*asin(.45/2). Speed is exp(Gaussian field), so log change is exactly the difference of Gaussian values. These are marginal superpopulation targets, not a claim that the expected finite-63 sample correlation equals its population target. Record finite-sample bias separately.

Methods: exact province pairs bootstrap; earlier k-means cluster pairs bootstrap K=6,8,12; experimental spatial Gaussian-multiplier bootstrap of centered delete-one jackknife influence estimates. The candidate multiplier covariance is exp(-chord_distance/bandwidth), with bandwidth one and two times the median fifth-neighbour distance; eigenvalues are checked, and materially indefinite matrices fail. This borrows the dependent multiplier mechanism from Conley, Goncalves, Kim and Perron, https://doi.org/10.3982/QE1626, not an established finite-sample validity result for these rank statistics. Its linearization, centering and bandwidth choice all require evaluation. It is not advertised as an exact implementation of the paper's regression algorithm.

For province/cluster samples use multiplicities and recompute exact weighted midranks equivalent to repeating observations, including ties and variable cluster sample sizes. Verify against scipy.stats.spearmanr on explicit repeated samples. Never bootstrap ranks fixed at the original sample. Cluster bootstrap and province bootstrap use percentile intervals and the earlier two-tail sign p with +1 correction. Multiplier intervals use the centered perturbation distribution around the observed statistic. Report invalid draws rather than silently replacing them; any invalid draw prevents that replicate from producing a p or interval.

Pilot: 12 simulated datasets and 199 bootstrap draws per configuration, four dependence levels on each graph, with rounded-X versions additionally at the independent and strongest adjacency levels. Ten configurations, four statistics, six methods. The pilot's 0.01 p threshold is at the Monte Carlo resolution floor and has no calibration interpretation. Also benchmark one dataset at B=1999 under each graph to estimate main-run time. Root seed 20261024 with separate SeedSequence keys for datasets and methods. Include swap/sign invariance and seeded rerun checks. Store pilot and benchmark separately.

Main-run projection: report measured cost scaled to at least 2000 datasets/configuration and B=1999, with an explicit warning that scaling is approximate. Do not automatically launch the full grid from this pilot command. The earlier NEXT_VERIFICATION_SPEC remains the broader evaluation plan, including further heterogeneity and simulation configurations not implemented in this core pilot.
