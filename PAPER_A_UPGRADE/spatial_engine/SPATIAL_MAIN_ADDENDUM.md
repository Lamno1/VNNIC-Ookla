# Spatial main evaluation: specification fixed before running, 24 October 2026

Written after exposure to the study results and after the small pilot; not external preregistration. It follows NEXT_VERIFICATION_SPEC_20261024.md and SPATIAL_PILOT_ADDENDUM.md, and reuses the pilot engine (spatial_pilot.py) unchanged. Nothing here is chosen from pilot rejection rates, which were uninterpretable at 12 datasets.

Size: 2,000 simulated datasets per configuration, 1,999 bootstrap draws (or multiplier draws) per dataset, root seed 20261024, separate SeedSequence keys (graph ids offset by 100 so that no pilot stream is reused). Datasets run in chunks of 250; chunk files are kept.

Configurations (14):
1. The ten pilot configurations: two graphs (adjacency, symmetric 5-nearest-neighbour) times SAR strength 0, .3, .6, .85 with the same spatial factor in V, O and X; the rounded-X variant (round(x*3)/3) at strength 0 and .85 on the adjacency graph. Tie fraction is reported as 1 - distinct/N, per dataset.
2. Four new configurations with different spatial dependence in the two sources, on each graph: (V strength 0, O strength .85) and (V strength .85, O strength 0), X strength .6. The Moran values of the observed VNNIC (-0.10) and Ookla (0.53) series motivate the first of these; the reverse order is included so that the result does not depend on which source is the dependent one. The strengths are parameter levels, not claims that the observed Moran statistic equals any value.

Generator: innovations with channel covariance [[1,.45,.25],[.45,1,.25],[.25,.25,1]] and AR(1) time covariance .7 over 16 quarters, drawn jointly; channel c is then multiplied by its own row-normalized SAR factor, so every marginal variance is 1.

Targets. Symmetric configurations (item 1): Delta = 0 by exchangeability of V and O; Q2 first-minus-last = 0 and mean-quarterly last-minus-first = 0 by stationarity; L4 target = 6/pi * asin(.45/2) (population). Different-dependence configurations (item 2): V and O are no longer exchangeable, so no target is assumed. Each target is the mean of the estimator over 20,000 independent reference datasets drawn from the same generator (separate seed keys), with its Monte Carlo standard error reported; this includes the finite-N bias of Spearman statistics, and coverage there refers to that expected value. Rejection of zero in these configurations is a power-type quantity, not a type I error, and is labelled so. Type I error is reported only where the target is exactly zero by symmetry.

Methods: exact province pairs bootstrap; k-means cluster pairs bootstrap K = 6, 8, 12 (groups fixed from the real centroids); the experimental spatial Gaussian-multiplier bootstrap on centred delete-one jackknife influence values with bandwidth 1 and 2 times the median fifth-neighbour distance. Percentile intervals; p = 2 min(add-one tails), capped at 1. A dataset with any invalid draw yields no p or interval for that statistic and is counted.

Reported per configuration, method and statistic: type I error at .05 and .01 (symmetric targets), coverage of the 95 percent interval, mean length, mean bias, Monte Carlo SE (sqrt(p(1-p)/n_valid)), invalid draws, tie fraction. All configurations and methods are reported, including failures; no method is dropped or tuned afterwards.

Interpretation rules fixed now: a method is called adequately calibrated for a configuration only if type I error at .05 lies within two Monte Carlo SE of .05 and coverage within two SE of .95 in that configuration. Adequacy in a simulated configuration is not a general certificate; failures in the configurations nearest the observed pattern (item 2, first order) limit the inference the paper may draw from the real-data p-values and intervals. The real data are not re-analysed in this run.

## Amendment 1 (24 October 2026, before the matched run): configurations matched to the observed Moran statistics

The main run used spatial strengths that were not matched to the real series. moran_match.py applies the observed Moran statistic (5 nearest neighbours, scaled lon/lat centroids, row-standardised; the definition of the earlier check) to simulated single-channel SAR fields, 4,000 draws per strength, and finds the strength whose mean I equals the observed I (moran_match_curve.csv, moran_match_summary.json). Observed I: VNNIC log speed Q2 2024 -0.103, Ookla 0.525, DTI 2023 infrastructure 0.108, NSO individuals 2021 0.389, households 2025 0.427. Matched strengths (adjacency / knn graph): Ookla 0.81 / 0.81; DTI 0.32 / 0.34; NSO 0.71 / 0.71; households 0.74 / 0.74. VNNIC: no non-negative strength gives a mean I as low as -0.103 (strength 0 gives -0.017, SD 0.07); the observed value lies inside the central 95 percent band for strengths 0 to 0.1, so strength 0 is used.

Matched run: V 0.0, O 0.81, and X 0.32, 0.71 or 0.74 for the three headline indicators, on each graph (6 configurations, ids 14 to 19), otherwise identical to the main run (2,000 datasets, 1,999 draws, same methods, same reference-target rule, separate seed keys). Strengths are fixed now, from Moran values only, not from any rejection rate. Known limitation: a single SAR factor per channel cannot reproduce both the level and the change patterns (observed log-change I: VNNIC 0.038, Ookla 0.243, which correspond to lower strengths, 0.15 and 0.54, than the level fields). The same observed-value-independent assumption (persistent spatial structure shared by all quarters) is therefore only approximate.
